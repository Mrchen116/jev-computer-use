# 旧版网页阶段执行器实测结果 — 2026-09-22

本文全部数据对应旧版 `--legacy-stages`，**不代表当前默认的通用 task 协议**。新版真实评测仍未达到降本和完成率目标；详见[当前状态](STATUS.md)及[新版开发比较](general-development-comparison.json)。保留以下旧版数据用于复现，不沿用其结论评价新版。

冻结版本达到预设工程目标：四类真实网站任务各重复两次，**双方均 8/8 成功，Jev 版 API 等价费用降低 58.2%，总耗时减少 4.9%**。这是小样本工程验收，不是通用成功率或统计非劣性的证明。

## 真实网站对照

两边均实际运行 Codex `gpt-5.6-sol` / `medium`、标准服务等级和原生 Computer Use。Jev 版增加统一 Skill 的委派工具，由同一个外层 Sol 负责规划、输入和最终核验。代码、指导文档、任务及标准在运行前冻结；重复编号 211、257，先后顺序交替。所有纠错与重试都计入。

每格为两次任务的平均值；每项双方均为 2/2 成功：

| 任务 | 原生费用 | Jev 版费用 | 降本 | 原生时间 | Jev 版时间 |
|---|---:|---:|---:|---:|---:|
| 最新 GitHub issue | $0.62076 | $0.27232 | 56.1% | 187.3 s | 198.9 s |
| Python 官方文档比较 | $0.40186 | $0.12073 | 70.0% | 105.3 s | 69.9 s |
| 三个官网资料收集 | $0.48060 | $0.18044 | 62.5% | 116.6 s | 111.0 s |
| 个人网站项目查找 | $0.18230 | $0.13035 | 28.5% | 42.0 s | 49.3 s |

八次总计：原生 **$3.37106 / 902.37 s**；Jev 版 **$1.40768 / 858.25 s**。issue 和短项目查找仍较慢，文档比较更快。

## 费用明细

按每次真实响应的 token usage 和运行前冻结的 API 单价计算，**不是订阅账户实际扣款账单**。缓存按缓存价，推理 token 已含在输出中，不重复收费。缺失计费的失败保持未知，不按零处理。

| 两轮累计 | 原生 Sol | Sol + Jev |
|---|---:|---:|
| Sol 请求数 | 79 | 40 |
| Sol 输入 token（含缓存） | 3,515,658 | 921,579 |
| 其中缓存输入 | 3,058,432 | 722,432 |
| Sol 输出 token（含推理） | 15,939 | 15,163 |
| Jev 输入 token | 0 | 449,076 |

Sol 每百万 token：普通输入 $4、缓存输入 $0.40、缓存写入 $5、输出 $20；Jev 输入 $0.042、输出 $0。来源与核价日期见[协议](PROTOCOL.md#metrics-and-accounting)。本轮缓存写入为零，最大单请求输入为 83,703 token，低于所用价格档位的上限。

Jev 本身合计 **$0.01886**，其余 **$1.38882** 为外层 Sol。Sol 请求减少 49.4%，输入 token 减少 73.8%。主要收益来自减少外层往返和重复页面上下文。

墙钟时间包括 Codex 启动、推理、原生工具、委派、重试和最终回答；双方窗口准备与清理均单独记录、不计入任务时间。

## 第五类：实时小游戏

同一冻结版本另跑两次 Jev 游戏，均 **12/12，零超时、零错选**：

| 重复 | 完整任务时间 | Sol + Jev 费用 | 反应时间范围 |
|---|---:|---:|---:|
| 211 | 57.43 s | $0.07786 | 1.50–1.87 s |
| 257 | 57.24 s | $0.07745 | 1.52–2.27 s |

每个请求由独立服务器时钟设置 **4 秒截止时间**，不会等模型返回才推进。通过标准预先固定为至少 10/12。原生端历史尝试因误操作浏览器控件、离开游戏后被停止，最终分数与完整费用未知；按用户要求没有重跑。因此这里只报告 Jev 功能和反应时间，不计算游戏的成对节省比例，也不能据此断言所有 LLM 都玩不了实时游戏。

外层分别选择 `realtime` 的 150 / 100 ms 周期下限及 `recheck_target: false`。真实循环约为上表所示的秒级反应时间；周期配置不保证推理速度，也不会并发堆积错过的周期。

这是文字可访问的语义选择游戏，不是马里奥、植物大战僵尸或像素游戏复现。[游戏数据](realtime-final.json)与[边界说明](../../docs/game-references.md)保留完整解释。

## 设计与审查

外层一次委派有界阶段：需要的原文、授权站点、已知网址和候选输入。Jev 连续选择操作，代码保存收集进度、原文来源和已尝试输入。跨域无需强制交回外层，长文其余内容可继续读取。外层按批核验、补充输入并决定下一阶段和最终完成。

实测出现过 Jev 误选 pytest 介绍片段。外层拒绝不足的证据并补查，相关费用全部保留。`collection_ready` 只代表候选证据收齐，没有网站专用完成规则，也不让 Jev 判断开放式研究是否充分。

`step` 与 `realtime` 共用读取 → Jev 决策 → 执行的顺序循环；外层选择模式、周期和是否额外检查目标。进展文件提供阶段、完成项、剩余项、近期动作与聚合 warning，支持查看、停止和切换模式。

[逐次脱敏数据](multisite-frozen.json)包含用量、耗时、模型确认、委派计数、定价及源文件 SHA-256。源文件哈希全部匹配，模型与 medium 强度从会话记录核验。审查了 16 个最终答案和工具记录；候选仅使用原生 UI、委派和保存证据工具，未通过 shell、网络 API 或隐藏页面状态取得答案。原生侧保留截图、AX 差分和确定性批量操作能力。

观察到的站点均在授权范围；运行后复核最新 issue 仍为 #298，没有参考漂移。临时认证副本已清理。原始私有日志和对应代码快照留在本机，未发布凭据或个人窗口记录。
